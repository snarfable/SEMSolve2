\subsection{Detailed Description}
This is a slightly modified version of the Yale Sparse Matrix Format. The typical Yale format would, in the place of double $\ast$$\ast$mvec, have a double $\ast$A type and an additional array, int $\ast$IA, which stores the index into A at which row i would begin. For example, A\mbox{[}IA\mbox{[}i\mbox{]}\mbox{]} is the first non-zero entry in row i of the matrix stored in A. Instead of this, I have used a double pointer to represent variable-length rows in a matrix. It is equivalent to if not better than using the additional IA vector because it takes a tiny amount of pointer arithmetic out of the act of dereferencing a value in the matrix. The double $\ast$lvec variable is such that lvec\mbox{[}i\mbox{]} is the number of non-zero entries in row i of the matrix. \begin{Desc}
